# Workspace Guidelines & Rules

## Faculty and PI Naming Conventions
- **Preserve Specific Titles**: Do NOT bulk-replace or force uniform prefixes (such as `Prof.` or `Prof. (Dr.)`) across all faculty, PIs, co-PIs, and guides.
- **Specific Designations**:
  - Only specific professors have `Prof. (Dr.)` (e.g., `Prof. (Dr.) Sudipta Sahana`).
  - Some faculty members hold `Dr.` (e.g., `Dr. Aniruddha Ghosh`, `Dr. Anjan Kumar Payra`, `Dr. Himadri Sekhar Panda`, `Dr. Ramen Pal`, `Dr. Harshit Srivastava`).
  - Some faculty members hold `Prof.` (e.g., `Prof. Anasuya Sengupta`, `Prof. Debdatta Chatterjee`, `Prof. Aniruddha Das`).
- Always respect and preserve manual adjustments to faculty names, project PIs, and guides.

## Publication and Annexure Author Names
- **NEVER use academic prefixes**: In `publications` and `annexures` author lists (`authors: [...]`), NEVER include `Prof.`, `Dr.`, `Prof. (Dr.)`, or any other title/honorific.
- Author names must always be pure/plain names (e.g., `"Sudipta Sahana"`, `"Anasuya Sengupta"`, `"Aniruddha Ghosh"`, `"Anjan Kumar Payra"`).
- Faculty profile matching handles normalized name comparisons, so plain names in publication lists correctly link to faculty profiles.
